# RQ3 tools

- `RQ3BatchRunner/` is the .NET batch runner.
- `scripts/` contains PowerShell scripts for dataset preparation, B0/B1/B2 execution, scoring, and readiness checks.
- `Run-System2.ps1` and `Verify-Package.ps1` are entry points for execution and package-integrity checks.

Run the scripts from the repository root on Windows PowerShell. The original detailed guide (`experiments/rq3/docs/HUONG_DAN_TAT_CA.md`) is not included in this staging copy; review the scripts and their required .NET version, endpoint configuration, and freeze/scoring rules before running them.
