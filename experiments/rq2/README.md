# RQ2 experiment

The RQ2 material was imported from a package supplied by a team member on 12 September 2026. This repository includes selected result exports under [`../../results/rq2/`](../../results/rq2/), the .NET source under [`../../src/Rq2Experiment/`](../../src/Rq2Experiment/), and helper scripts under [`../../tools/rq2/`](../../tools/rq2/).

The task manifests are included under [`../../datasets/rq2/`](../../datasets/rq2/); the original package's `docs/` and `archives/` are not included. Some source documents refer to a former `dataset/` path, which corresponds to `datasets/rq2/`. The staged raw result files retain their batch names. For the 100-unit analysis reported in the manuscript, use the 297-row main batch together with the three-row replacement batch, as described in the top-level README.
